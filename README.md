# Histoglyph — V12

Den här versionen bygger om projektet från ett enskilt spel till en webbplattform som kan innehålla flera spellägen och samlingar.

## Sidstruktur

```text
index.html
  Startsida för Histoglyph
  └── spellägen
       └── life-map.html
            Samlingar/kategorier för Life & Death Map
            └── play.html?collection=world-history
                 Själva spelet

admin.html
  Hantering av personer, platser och samlingstaggar
```

## Nuvarande spelläge

**Life & Death Map** är det spel som redan har byggts. På dess samlingssida finns:

- World History — spelbar
- American Presidents — förberedd men markerad som Coming soon
- North American Figures — förberedd
- European Monarchs — förberedd
- The Renaissance — förberedd
- fler regionala exempel

## Så lägger du till en ny samling

Samlingarna definieras i:

```text
data/game-catalog.js
```

Exempel:

```javascript
{
  id: "american-presidents",
  group: "North America",
  title: "American Presidents",
  status: "available",
  roundLimit: 5,
  filter: { anyTags: ["american-president"] }
}
```

I adminpanelen anger du sedan taggen `american-president` på alla personer som ska ingå. När samlingens status ändras från `coming-soon` till `available` blir den spelbar.

## Samma födelse- och dödsort

När en person föddes och dog på samma plats visas nu:

- en enda punkt
- vänster halva grön
- höger halva röd
- födelseår och dödsår tillsammans, exempelvis `1907–1954`
- ortnamnet visas vid samma kombinerade punkt efter avslutad runda

## Kartan under spelet

Kontinentknapparna är borttagna från själva spelet. Kartan zoomar automatiskt till ledtrådarna, men spelaren kan fortfarande zooma och panorera med kartans vanliga kontroller.

## Taggar och datamodell

Personposter har nu fältet:

```text
tags: string[]
```

Taggar kan hanteras i adminpanelen och följer med i CSV- och JSON-exporter. Detta är grunden för framtida kategorier som:

- `american-president`
- `north-america`
- `european-monarch`
- `renaissance`

## Starta projektet

1. Packa upp ZIP-filen.
2. Öppna mappen i Visual Studio Code.
3. Starta `index.html` med Live Server.
4. Gå från startsidan till Life & Death Map och välj World History.

## V13 additions

- Selecting an available collection opens a game-settings dialog.
- Players can choose timed or untimed play.
- Players can choose whether place names are shown before guessing.
- Untimed correct answers award 1000 points.
- The Places editor now uses only `Name`; historical name and country code were removed.
- `starter-data/` contains import-ready CSV files for 20 additional historical people and their places, including collection tags.


## Version 14 updates

- Fixed the game map loader by cleaning the local SVG and assigning its URL only after load/error handlers are attached.
- Public pages now use bundled classic JavaScript files, so the game is less sensitive to ES-module loading restrictions.
- Players can choose 1–100 rounds before starting.
- Timed mode continues to use points.
- Untimed mode removes points and displays the number of correct answers instead.
- If the selected number of rounds is larger than the number of available people, the game reuses people only after every available person has appeared once.


## Version 15 — admin map alignment

- The admin verification map now uses the exact same aspect ratio and Robinson projection as the game map.
- The blue editable marker and map-click coordinate conversion are aligned with the visible coastline.
- The map keeps the same coordinate system at desktop and mobile widths.
- The SVG image is explicitly scaled to the marker layer, preventing browser-dependent letterboxing.


## Version 16 — corrected map projection

Both the game and the data manager now use the exact cubic Robinson interpolation used by PROJ/Basemap, rather than a simplified linear approximation. The map containers are locked to the SVG viewBox ratio `1419.6 / 719.98`, and conflicting admin height rules have been overridden.

To run the included numerical projection check:

```bash
node tools/validate-projection.cjs
```

The check compares London, New York, Stockholm, Cairo, Tokyo and Sydney with reference positions generated by the same Basemap Robinson projection that created the SVG.
