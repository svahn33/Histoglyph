# Histoglyph starter data — 20 historical people

Import the files in this order:

1. `histoglyph-20-people-places.csv`
2. Review the imported places in Data manager.
3. `histoglyph-20-historical-persons.csv`

All people already contain collection tags. The place rows are marked as
`automatically_matched`, so their coordinates can be checked on the detailed map
before a final public release. The person rows are set to `published=true` so they
can be tested immediately after import.

A source list is included in `SOURCES.md`.
