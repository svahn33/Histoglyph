# Sources for the 20-person starter pack

The CSV files are intended as import-ready starter data. Place rows use OpenStreetMap links in their `source` column and are deliberately marked `automatically_matched` so the markers can be reviewed in Histoglyph before final publication.

- George Washington — https://www.nps.gov/gewa/learn/historyculture/george-washington.htm
- Abraham Lincoln — https://www.nps.gov/people/abraham-lincoln.htm
- Thomas Jefferson — https://www.monticello.org/biography-of-jefferson
- Theodore Roosevelt — https://www.nps.gov/articles/000/theodore-roosevelt-biography.htm
- John F. Kennedy — https://www.nps.gov/people/jfk.htm
- Queen Victoria — https://www.royal.uk/encyclopedia/victoria-r-1837-1901

- Peter the Great — https://www.encyclopedia.com/international/encyclopedias-almanacs-transcripts-and-maps/peter-i-1672-1725

Some historical birth/death sites are estates, palaces or villages rather than modern municipalities. Histoglyph therefore stores the named historical locality/site used for the clue, together with a coordinate that should be visually reviewed in Data manager.
